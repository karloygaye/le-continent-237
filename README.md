# Leprince Karloy — site de présentation

Site vitrine pour **Leprince Karloy**, création de flyers et affiches sur mesure à Paris.

Le fichier `code(6) (1).txt` n’était pas joint à l’environnement : cette page reprend le brief (présentation du site, flyers sur mesure) et l’affiche dans un aperçu navigateur.

## Lancer en local

```bash
npm install
npm run dev
```

Le serveur écoute sur [http://127.0.0.1:43141](http://127.0.0.1:43141).

## Contenu

- Accueil avec la direction artistique
- Six travaux présentés comme des affiches
- Trois formules (flyer unique, série, identité de soirée)
- Formulaire de brief (validation côté client, pas d’envoi e-mail)

## Build

```bash
npm run build
npm run preview
```

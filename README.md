# Le Continent 237

Site du restaurant **Le Continent 237 — Chez Fefe**, grill au feu de bois à Juvisy-sur-Orge.

Cuisine camerounaise : ndolé, poulet DG, poisson braisé, mbongo. Réservation au 01 69 38 30 23.

## Lancer en local

```bash
npm install
npm run dev
```

Ouvrez [http://127.0.0.1:43141](http://127.0.0.1:43141).

## Contenu

- Accueil, horaires et adresse (18 Grande Rue, 91260)
- Histoire Chez Fefe
- Carte complète (onglets)
- Galerie
- Formulaire de demande de table (confirmation par téléphone)

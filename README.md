# Le Continent 237

Site du restaurant **Le Continent 237 — Chez Fefe**, grill camerounais au feu de bois, 18 Grande Rue, 91260 Juvisy-sur-Orge.

Les demandes de table s’envoient sur **WhatsApp** (+33 6 66 60 17 59). La carte complète se télécharge en PDF : [`public/carte.pdf`](public/carte.pdf).

Pour régénérer le PDF :

```bash
pip install fpdf2
python3 scripts/generate_menu_pdf.py
```

## Lancer

```bash
npm install
npm run dev
```

Ouvrez [http://127.0.0.1:43141](http://127.0.0.1:43141).

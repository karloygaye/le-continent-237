# Le Continent 237

Site du restaurant **Le Continent 237 — Chez Fefe**, grill camerounais au feu de bois, 18 Grande Rue, 91260 Juvisy-sur-Orge.

Les demandes de table s’envoient sur **WhatsApp** (+33 6 66 60 17 59). Un concierge IA (dans le navigateur, sans envoi de données) conseille la carte.

Pour remplacer la vidéo d’ambiance, déposez un fichier `ambiance.mp4` dans `public/` (MP4 H.264, idéalement 16:9).

## Lancer

```bash
npm install
npm run dev
```

Ouvrez [http://127.0.0.1:43141](http://127.0.0.1:43141).

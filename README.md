# Le Continent 237

Site du restaurant **Le Continent 237 — Chez Fefe**, grill camerounais au feu de bois, 18 Grande Rue, 91260 Juvisy-sur-Orge.

Les demandes de table s’envoient sur **WhatsApp** (+33 6 66 60 17 59). Le concierge IA utilise un modèle gratuit réel (**gpt-oss** via Pollinations, secours OVHcloud) — aucune clé API n’est requise.

## Lancer

```bash
npm install
npm run dev
```

Ouvrez [http://127.0.0.1:43141](http://127.0.0.1:43141).
